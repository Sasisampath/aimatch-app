# AI Compass


**AI Compass** is a sleek, ultra-fast web application designed to help users navigate and stay ahead in the rapidly evolving landscape of Artificial Intelligence—all in just 60 seconds a week. By leveraging a gamified, micro-learning approach, users can quickly gauge their alignment, knowledge, or matches within the AI space through a rapid-fire series of swipe questions.

Built by **JAZZHQ**.

---

## 🚀 Features

* **Micro-Learning Concept:** Designed for busy individuals to stay updated or discover AI insights in under a minute.
* **Gamified Swipe Interface:** Uses a intuitive, interactive 10-question swipe mechanism (similar to card-swiping mechanics).
* **Sleek Dark Mode UI:** High-contrast, minimalist design featuring neon accents for an immersive, modern tech aesthetic.
* **Responsive & Fast:** Fully optimized for both desktop and mobile web viewports.

---

## 🛠️ Tech Stack

* **Frontend Framework:** Next.js / React.js (implied by deployment environment)
* **Styling:** Tailwind CSS (for modern typography and custom color branding)
* **Hosting & Deployment:** [Vercel](https://vercel.com)

## 📦 Installation & Setup

To run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone [https://github.com/YOUR_USERNAME/ai-compass.git](https://github.com/YOUR_USERNAME/ai-compass.git)
cd ai-compass


2. Install dependencies
Bash
npm install
# or
yarn install
# or
pnpm install


3. Run the development server
Bash
npm run dev
# or
yarn dev
# or
pnpm dev


Open http://localhost:3000 with your browser to see the result.
